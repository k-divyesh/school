# Basic UNIX/Linux Concepts

## Commands

### Basic Commands

- pwd tells you which directory you're in; it stands for _print working directory_
- who: tells which users are logged into the system
- whoami: user's username

### Navigation Commands

- ls list, cd change directory

### Interface Commands

- clear- clears all text from screen
- history- shows running history of commands ran

### help Commands

- man command shows manual for given command
- whatis command shows description for given command straight from manual

### Interrupting Commands

- ctrl + c interrupts a task

## Editors

- linux comes with vi, nano and emacs

## File Transfer

- _sftp_ secure file transfer protocol, installed by default on mordern OSes
- Graphical Programs: Filezilla, Cyberduck
