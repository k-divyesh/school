## Bits and Bytes
  - bit has two values  
  0 &rarr; low, false, clear  
  1 &rarr; high, true, set  
  
  - unit of 8 bits = a **byte**.

## Bit Patterns
  - n bits can have 2 raise to n values.
  - ASCII &rarr; American Standard Code for Information Interchange
    - 7-bit code
    - representing up to 2 raise to 7 = 128 characters
  - Today, the 16-bit unicode has been devised to represent much greater range of characters.

## Numbers and Binary Arithmetic
  - in positional notation system, a sequence of digits is written in the format a~n-1~ a~n-2~ ... a~i~ ... a~1~ a~0~
  - ex. when N = 278, a~2~ = 2, a~1~ = 7, a~0~ = 8
  - &rarr; N = a~n-1~ x b^n-1^ + a~n-2~ x b^n-2^ + ... + N = a~0~ x b^0^\
    &rarr; N = 2x10^2^ + 7x10^1^ + 8x10^0^


- any integer number can be *accurately* converted into/from one base to another

- some fractions cannot be converted from one base to another. Ex: 0.1 base 10 cannot be *accurately* converted into a binary form.

## range, precision, accuracy and errors

- *range*: total set of numbers that can be represented with a given number of bits(or location for other bases), from it's lowest value(0) to highest(2^n - 1)

- total number of possible values that can be held in n bits = 2^n

- *precision*: measure of how well we can represent a number

- ex: 3.1415's precision is 1 in 10^5 or 5 significant figures
.. ex: 3.141592653's precision is 1 in 10^10 or 10 significant figures

- *accuracy*: difference in between representation and actual value.
