## Bits and Bytes
  - bit has two values  
  0 &rarr; low, false, clear  
  1 &rarr; high, true, set  
  
  - unit of 8 bits = a **byte**.

## Bit Patterns
  - n bits can have 2 raise to n values.
  - ASCII &rarr; American Standard Code for Information Interchange
    - 7-bit code
    - representing up to 2 raise to 7 = 128 characters
  - Today, the 16-bit unicode has been devised to represent much greater range of characters.


## Numbers and Binary Arithmetic
  - in positional notation system, a sequence of digits is written in the format $ a_{n-1} a_{n-2} ... a_i ... a_1 a_0 $\
  - ex. when $ N = 278, a_2 = 2, a_1 = 7, a_0 = 8 $\
  - &rarr; $ N = a_{n-1} x b^{n-1} + a_{n-2} x b^{n-2} + ... + a_0 x b^0 $\
    &rarr; $ N = 2x10^2 + 7x10^1 + 8x10^0 $\
